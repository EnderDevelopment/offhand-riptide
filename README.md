# Offhand Riptide

Offhand Riptide is a Minecraft plugin that automatically equips a trident in the offhand slot of players when they join the game. This plugin is designed to enhance the gameplay experience by providing quick access to riptide tridents, which are essential for underwater travel and combat.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Join the Minecraft server where the plugin is installed.
2. Upon joining, you will automatically receive a trident in your offhand slot.
3. Use the trident to riptide through water or to attack enemies.
